# CTA library

All copy below is taken or adapted from live pages (`/wonderland-concierge`,
`/plan-your-destination-wedding`, `/wonderland-studio`), read 22 October 2026.
The brief picks one primary CTA and optionally one soft CTA. The writer uses
the copy as written (light edits for context are fine; never change the
promise). In the CMS, CTAs are placed with the shared CTA block, never typed
into the body. Never put a price in a CTA (see brand-profile, Prices).
