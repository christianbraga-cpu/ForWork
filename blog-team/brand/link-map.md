# Internal link map

Source of truth: **WW Internal Link Targets** (marketing team, October 2026),
plus related articles found by a Firecrawl map of weddedwonderland.com on
22 October 2026. All URLs below are on `https://weddedwonderland.com`. Write
links as root-relative paths (e.g. `/wonderland-concierge`).

The writer links only to URLs in this file. The SEO reviewer blocks anything
in the "Do not link" section. Propose a missing target as `[[LINK NEEDED: topic]]`.

## How to choose links for a post

1. **Always:** one Concierge link (`/wonderland-concierge`) and the most
   specific destination page for the post (area page, else country, else region).
2. **Australia or Melbourne angle:** link Wedded World Melbourne
   (`/wedded-world/melbourne`). The event is **7 and 8 November 2026**; after
   that date link `/wedded-world` instead.
3. **Related:** 2 or 3 related articles from the tables below, chosen by topic.
4. **Celebrations with no page yet** (babymoon, anniversary, proposal, vow
   renewal, milestone birthdays): link `/travel`, `/destination-packages` or
   `/wonderland-concierge` until a page exists.
5. **Vendors and venues:** when a post names a vendor or venue that has a
   profile on our site (179 vendor and 72 venue profiles), link its profile
   under `/vendor/<slug>` or `/venue/<slug>`. Confirm the profile exists with
   a Firecrawl map search before linking.
6. **Planning tools:** guest list, RSVP, budget, seating or wedding website
   topics link Wonderland Studio. Culture-specific posts link the matching
   website template.
7. **Cannibalisation:** never use an exact-match anchor for a keyword another
   page already owns (see "Owns" columns). If a new post's keyword overlaps an
   existing page, the brief must say how it differs and link to that page.
