# Wedding guest list checklist

Use this alongside the wedding guest list template (.xlsx). Work through it once when you set the file up, again before the save the dates go out, and again before the invitations. Column names match the template exactly.

## 1. Guest list set-up

### Households
- [ ] Give everyone who shares an invitation the same **Household ID** (for example H001, H002).
- [ ] Add one row per person under each household, starting at row 7 of the Guest list tab. Overwrite or delete the example in row 6.
- [ ] Keep **First name** and **Last name** in their own columns so the list sorts by family name.
- [ ] Fill in **Age group** (Adult, Teen, Child or Infant) for every guest.
- [ ] Use **Side** (Partner A, Partner B or Both) for counting only.
- [ ] Leave **List (optional)** empty unless you have chosen to invite in rounds.

### Envelope names
- [ ] Write the **Envelope name** once per household, on the first row, exactly as the invitation will be addressed.
- [ ] Check envelope names against how each household writes its own names, not how you say them.
- [ ] Fill in the five address columns (**Street**, **City**, **State or region**, **Postcode**, **Country**) before anything goes to the stationer.

### The plus-one and children rule
- [ ] Agree the plus-one rule and the children rule once, before the first row goes in.
- [ ] Type the rule into the cell for it on the How to use tab, so everyone helping works to the same rule.
- [ ] Give every plus-one a name in **Plus one name**. A yes is not enough for a place card.

### Invitations for each event
- [ ] For each event (**Welcome dinner**, **Ceremony**, **Reception**, **Recovery brunch**), set every guest to Not invited or Invited before anything goes out.
- [ ] Enter a date, not a tick, in **Save the date sent** and **Invitation sent**.
- [ ] As replies arrive, change Invited to Attending or Declined for each event.
- [ ] Use the filters in row 5 to find everyone still marked Invited for an event.
- [ ] Fill in **Meal choice**, **Dietary needs and allergies** and **Access needs** separately. Ask about access needs early.
- [ ] Fill in **Table** last, once replies settle.
- [ ] Check the Summary tab after each round of replies. Don't type over its formulas.

## 2. Destination travel

The eight Destination travel columns, in the order they sit in the file:

- [ ] **Travelling from**: city and country for each guest.
- [ ] **Flights booked**: Yes or No. Filter for No to see who still has a seat to find.
- [ ] **Arrival date**: day/month/year. Check it against the welcome dinner.
- [ ] **Departure date**: day/month/year. Check it against the recovery brunch.
- [ ] **Accommodation**: where each guest is staying, in their own words.
- [ ] **Transport to venue needed**: Yes or No. Read it together with **Access needs**.
- [ ] **Visa letter needed**: Yes when a guest asks you for a letter for their visa application.
- [ ] **Visa letter sent**: Yes once you have sent it. The Summary tab counts the letters still to send.

### Visa letters
- [ ] Visa rules belong to each guest. Each guest checks the visa and entry requirements for every country they are visiting or transiting through with the embassy or consulate of the destination, before they travel.
- [ ] Send that reminder with the save the date, not the invitation.
- [ ] Don't tell guests what a visa or visa letter requires. Point them to the destination's embassy or consulate.

## 3. Privacy

- [ ] Remember what the file holds: names, addresses and phone numbers are personal information, and the dietary and access columns can reveal a good deal about someone's health.
- [ ] Share the file only with the people who need it, and give view-only access to anyone who doesn't need to edit.
- [ ] Keep it out of group chats and screenshots.
- [ ] For a parent or helper chasing one side of the family, copy the names and reply columns into a separate file rather than handing over every address.
- [ ] Keep passport details out of the shared file. The template has no passport column.
- [ ] After the thank you notes have gone (**Gift**, **Thank you sent**), delete the file or move it somewhere only you, and anyone you trust to help, can open.

Privacy points here are general information as at November 2026, not legal advice. The guide links the official OAIC and Smartraveller sources at each point.
